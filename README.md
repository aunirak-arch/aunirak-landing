# อุ่นไอรัก หมอนของขวัญ (@aunirakgift) — Landing Page

หน้า landing page สำหรับโชว์สินค้าหมอนสกรีน/ของขวัญสั่งทำ ลูกค้าสั่งซื้อผ่าน LINE เท่านั้น (ไม่มีตะกร้า)
Export มาจากไฟล์ดีไซน์ใน Claude Design canvas — เป็น HTML/CSS/JS ล้วน ไม่มี build step เปิดไฟล์ในเบราว์เซอร์ได้ทันที

## ไฟล์

- `index.html` — หน้าเดสก์ท็อป (responsive รองรับจอเล็กด้วย media query + เมนูสามขีด)
- `mobile.html` — เวอร์ชันออกแบบเฉพาะมือถือ 390px (ใช้อ้างอิงดีไซน์มือถือ; เว็บจริงอาจใช้ index.html ตัวเดียว)
- `images/` — รูปทั้งหมดที่หน้าอ้างถึง (webp/png)

## สิ่งที่ยังเป็น [placeholder] ต้องเติมข้อมูลจริง

- ราคา/ขนาด: หมอนไดคัท, ผ้าห่ม, แก้ว (ทัมเบลอร์/มัค), กรอบรูป
- รีวิวจริง 3 รายการ + ชื่อลูกค้า
- หัวข้อ/ลิงก์บทความ 3 เรื่อง และ URL หน้ารวมบทความ (ตอนนี้ลิงก์ "ดูบทความทั้งหมด" ชี้ `#blog`)
- ที่อยู่ร้าน, เวลาทำการ, อีเมล (`mailto:[อีเมลร้าน]`), เงื่อนไขค่าส่ง
- Google Maps: วาง iframe embed แทนกล่อง placeholder ใน footer
- ตัวเลข "[จำนวน]+ ชิ้นที่ผลิตแล้ว" ใน hero (ถ้ามี)

## หมายเหตุสำหรับงานต่อ (SEO)

- ทุกส่วนมี anchor id พร้อมทำ internal link · รูปมี alt ภาษาไทยครบ
- meta description ใส่แล้วใน `<head>` — ควรเพิ่ม Open Graph, schema.org (LocalBusiness/Product), canonical ตอน deploy จริง
- แผนเดิมของเจ้าของ: ขึ้น WordPress + เขียนบทความ SEO (คีย์เวิร์ดต้องตรวจจาก Ahrefs ก่อนใช้เสมอ)
- ฟอนต์โหลดจาก Google Fonts (ต้องมีอินเทอร์เน็ต); ถ้าต้องการ self-host ให้ดาวน์โหลด Athiti + Noto Sans Thai มาไว้ในโปรเจกต์
